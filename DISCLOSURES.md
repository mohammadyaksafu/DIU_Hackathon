# Disclosures (Rulebook 4.4 / 9.2)

## External services
| Service | Use | Required? |
|---|---|---|
| Anthropic Claude API (`claude-opus-5-5` by default) | Natural-language case summaries and SOP answers. Never makes risk decisions. | Optional: deterministic templates are used without a key |

## Pre-trained models
None. All ML models (LightGBM, Isolation Forest, logistic-regression baseline) are trained from scratch on our synthetic data by `backend/pipelines/train.py`.

## Datasets
No external datasets. All data is generated by `backend/pipelines/generate_data.py` (seeded). Names are recombined from a short list of common Bangladeshi first/last names; phone numbers use the fake prefix `SYN-`. The SOP documents in `backend/knowledge/sop/` are written by the team for the demo and are **not** official upay documents.

## Open-source libraries (main)
Python: FastAPI, Pydantic, SQLAlchemy, Uvicorn, PyJWT, PyYAML, NumPy, pandas, PyArrow, scikit-learn, LightGBM, NetworkX, joblib, anthropic, redis-py, psycopg, pytest, httpx.
JavaScript: Next.js, React, Tailwind CSS, Recharts, d3-force, TypeScript.
All are used under their respective open-source licences.

## Pre-existing general-purpose components
None beyond the libraries above. All application code was written during the hackathon development period.

## Design references
The chart colour palette follows a validated, colour-blind-safe reference palette (checked with an automated palette validator).
